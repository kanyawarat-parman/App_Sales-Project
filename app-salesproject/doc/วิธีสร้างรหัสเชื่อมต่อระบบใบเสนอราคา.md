# วิธีสร้าง / เปลี่ยนรหัสเชื่อมต่อ ระบบงานขาย ↔ ระบบใบเสนอราคา

ปรับปรุงล่าสุด: 2026-10-15

## รหัสเชื่อมต่อคืออะไร
รหัสผ่านระหว่าง 2 ระบบ (ไม่ใช่รหัสของคน) — ระบบใบเสนอราคา (200.200.200.4) แนบรหัสนี้ทุกครั้งที่เรียกระบบงานขาย (host)
เพื่อดึงรายการคำขอใบเสนอราคา / ตรวจคำขอ / ส่งผลออกใบ — ระบบงานขายเทียบกับรหัสที่ตั้งไว้ ตรงกันจึงยอมให้ข้อมูล

**ต้องเป็นค่าเดียวกันทั้ง 2 ที่:**

| ระบบ | เครื่อง | ไฟล์ | ตำแหน่ง |
|---|---|---|---|
| ระบบงานขาย (app sales project) | host `sales.thaitaiyo.co.th` | `app-salesproject/config/config.php` | บรรทัด `define('QUOTE_API_TOKEN', '…');` ในชุด **ใบเสนอราคา - Host** |
| ระบบใบเสนอราคา | `200.200.200.4` | `webquotation\App_Data\appsettings.local.config` (โฟลเดอร์ตาม Physical path ใน IIS) | `<add key="SalesProjectApiToken" value="…" />` |

- คนที่รู้รหัสลาออกหรือย้ายงาน

## ขั้นที่ 1 — สร้างรหัสใหม่ (PowerShell)
เปิด **Windows PowerShell** บนเครื่องใดก็ได้ แล้วรันคำสั่งนี้ (คัดลอกทั้งบรรทัดไปวาง ไม่ต้องพิมพ์เอง):

```powershell
-join ((48..57)+(97..122) | Get-Random -Count 36 | % {[char]$_})
```

จะได้ตัวอักษรภาษาอังกฤษพิมพ์เล็ก + ตัวเลข ยาว 36 ตัว เช่น `k3m9x…` (ทุกครั้งที่รันได้ค่าใหม่)

- คัดลอกรหัสเก็บไว้ชั่วคราว (เช่น Notepad ที่ไม่บันทึกไฟล์) ใช้วาง 2 ที่ด้านล่าง
- **ห้าม** ส่งรหัสในแชท/อีเมล, ห้ามถ่ายภาพหน้าจอที่เห็นรหัส, ห้ามบันทึกรหัสลงไฟล์ใน git หรือในเอกสารนี้

## ขั้นที่ 2 — ใส่รหัสในระบบงานขาย (config.php)
1. เปิด `app-salesproject/config/config.php` บนเครื่อง
2. หาส่วน **เชื่อมระบบใบเสนอราคา** แล้วตั้งเป็นชุด Host:
   ```php
   // ใบเสนอราคา - localhost (token มาจาก env ของ dev server ebidding-qt)
   // define('QUOTE_API_TOKEN', envOr('QUOTE_API_TOKEN', ''));
   // define('QUOTATION_WEB_URL', envOr('QUOTATION_WEB_URL', 'http://localhost:57930/'));

   // ใบเสนอราคา - Host
   define('QUOTE_API_TOKEN', 'วางรหัสใหม่ตรงนี้');
   define('QUOTATION_WEB_URL', 'http://taiyo.dyndns.info:7789/webquotation/');
   ```
   - รหัสต้องอยู่ระหว่าง `'` กับ `'` ไม่มีช่องว่าง
   - บรรทัด `QUOTE_API_TOKEN` ที่ไม่มี `//` นำหน้าต้องมีบรรทัดเดียว (ประกาศซ้ำ PHP ใช้ค่าแรก)
3. สลับชุด LINE / SMTP / APP_URL เป็นของ host ตามปกติ แล้วอัปโหลด `config.php` ขึ้น host
4. **คืนไฟล์บนเครื่องเป็นชุด localhost** (ใส่ `//` ชุด Host กลับ) และลบรหัสจริงออกจากไฟล์บนเครื่อง

## ขั้นที่ 3 — ใส่รหัสในระบบใบเสนอราคา (200.200.200.4)
ไฟล์ `App_Data\appsettings.local.config` มี 2 ชุดแบบเดียวกับ config.php (ใช้ comment ของ XML `<!-- … -->` แทน `//`) — ตัวอย่างเต็มอยู่ที่ `App_Data\appsettings.local.config.example`

1. เปิด `App_Data\appsettings.local.config` บนเครื่อง dev
2. **ครอบชุด localhost ด้วย comment** และ **เอา comment ที่ครอบชุด Host ออก** แล้ววางรหัสใหม่ (ตัวเดียวกับขั้นที่ 2):
   ```xml
   <appSettings>

     <!-- ===== ชุด localhost (เครื่อง dev) =====
     <add key="SalesProjectApiUrl" value="http://localhost:8083/api/quote_requests_ext.php" />
     <add key="SalesProjectApiToken" value="รหัสของเครื่อง dev" />
     -->

     <!-- ===== ชุด Host (200.200.200.4) — URL ใช้ค่าใน Web.config ใส่แค่รหัส ===== -->
     <add key="SalesProjectApiToken" value="วางรหัสใหม่ตรงนี้" />

   </appSettings>
   ```
3. Save เป็น UTF-8 → อัปโหลดไปที่ `App_Data\` ในโฟลเดอร์เว็บ webquotation บน 200.200.200.4 (Physical path ใน IIS)
4. **สลับไฟล์บนเครื่อง dev กลับเป็นชุด localhost** และลบรหัส host ออก
5. **⚠️ ต้องให้เว็บเริ่มใหม่ทุกครั้ง** — ASP.NET อ่านไฟล์ App_Data ครั้งเดียวตอนเว็บเริ่ม และ **IIS ไม่เฝ้าดูไฟล์นี้** (ต่างจาก Web.config) แก้ไฟล์แล้วเว็บยังใช้รหัสเดิมในหน่วยความจำ (เจอจริง 2026-10-15: ไฟล์เป็นรหัสใหม่ แต่เว็บยังใช้รหัสเดิม → Unauthorized)
   - เปิด `Web.config` ในโฟลเดอร์เว็บ (ที่เดียวกับ App_Data) ด้วย Notepad → กด Space แล้ว Backspace → **Save** (Date modified ต้องเปลี่ยน)
   - หรือ IIS Manager → Application Pools → เลือก pool ของ webquotation → **Recycle…**

**ระวัง:**
- ห้ามมี `--` (ขีด 2 ตัวติดกัน) อยู่ในเนื้อหา comment — XML พัง เว็บใบเสนอราคา error ทั้งเว็บ
- ลืมครอบชุด localhost ก่อนอัปโหลด = เครื่องจริงไปต่อ `localhost:8083` → แถบแดง "Unable to connect … (ปลายทาง http://localhost:8083 …)" — แก้ไฟล์บนเครื่องจริงให้เหลือแค่ชุด Host
- เปิด 2 ชุดพร้อมกัน = ระบบใช้ `<add>` ตัวหลังสุดของแต่ละ key
- แก้ตรงบน 200.200.200.4 ก็ได้ (เปิดไฟล์บนเครื่องจริงแล้วแก้รหัสในชุด Host) — ไม่ต้องผ่านเครื่อง dev

> ทำขั้นที่ 2 กับ 3 ต่อกันทันที — ระหว่างที่รหัส 2 ที่ไม่ตรงกัน แท็บรอเปิดใบเสนอราคาจะขึ้นแถบแดง "Unauthorized"
> และ (ถ้าเปิดกฎล็อกแล้ว) ใบงานโครงการจะออกไม่ได้ชั่วคราว — ควรเปลี่ยนนอกเวลาทำงาน

## ขั้นที่ 4 — ตรวจผล
**วิธีที่ 1 (หน้าเว็บ):** เปิด `http://200.200.200.4/webquotation/quotation.html` → Ctrl+F5 → แท็บ **"รอเปิดใบเสนอราคา งาน Project"**
- ไม่มีแถบแดง = ใช้ได้ ✅
- แถบแดง "Unauthorized" = รหัส 2 ที่ไม่ตรงกัน → เทียบใหม่ทีละตัว
- แถบแดง "Unable to connect … (ปลายทาง …)" = เครื่องต่อ host ไม่ได้ (ไม่ใช่เรื่องรหัส) — ดูข้อความในวงเล็บ

**วิธีที่ 2 (PowerShell บน 200.200.200.4 — อ่านรหัสจากไฟล์ ไม่ต้องพิมพ์รหัส):**
```powershell
cd "วาง Physical path ของ webquotation"
$t = ([xml](Get-Content '.\App_Data\appsettings.local.config')).appSettings.add.value
$t.Length
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
(Invoke-WebRequest "https://sales.thaitaiyo.co.th/app-salesproject/api/quote_requests_ext.php?action=locked_sale_ids" -Headers @{"X-Quote-Api-Token" = $t} -UseBasicParsing).Content
```
- `$t.Length` ควรได้ 36
- ได้ `{"success":true,…` = รหัสตรงกับ host ✅ / ได้ error 401 = ไม่ตรง

## แก้ปัญหา: เปลี่ยนรหัสแล้วยังขึ้นแดง "Unauthorized" (รหัสที่ระบบใช้ไม่เปลี่ยน)
เจอจริงตอนขึ้นระบบ 2026-10-15 — **ไฟล์แก้ถูกทั้ง 2 ที่แล้ว แต่ระบบยังใช้รหัสเดิมในหน่วยความจำ** ทำให้ดูเหมือนรหัสไม่ตรง
อย่าเดา ให้ดู "รหัสที่แต่ละระบบใช้อยู่จริง" ด้วยไฟล์เช็คชั่วคราว 2 ไฟล์ (แสดงแค่ความยาว + 4 ตัวแรก + 4 ตัวท้าย ไม่เปิดเผยทั้งรหัส)

**ดูเร็วที่สุด:** แถบแดง "Unauthorized" บอก**ความยาว + 4 ตัวท้ายของรหัสที่ระบบใบเสนอราคาใช้อยู่จริง**ต่อท้ายข้อความ เทียบกับรหัสใหม่ได้ทันที
(มีตั้งแต่ `App_Code/clsSalesProjectApi.cs` รุ่น 2026-10-15 บ่าย — ถ้าแถบแดงไม่มีส่วนนี้ แปลว่าเครื่องจริงยังเป็นไฟล์รุ่นก่อน)

### ไฟล์เช็ค (เก็บไว้ในโปรเจกต์ — อัปโหลดเฉพาะตอนไล่ปัญหา แล้ว**ลบออกจากเครื่องจริงทันที**)
| ระบบ | ไฟล์ในโปรเจกต์ | อัปโหลดไปที่ | เปิดดูที่ |
|---|---|---|---|
| ระบบงานขาย (host) | `app-salesproject/api/_token_check.php` | `app-salesproject/api/` บน host | `https://sales.thaitaiyo.co.th/app-salesproject/api/_token_check.php?flush=1` |
| ระบบใบเสนอราคา (200.200.200.4) | `web_quotation/_token_check.aspx` | root ของเว็บ webquotation (ที่เดียวกับ `quotation.html`) | `http://200.200.200.4/webquotation/_token_check.aspx` |

### ขั้นตอนไล่ปัญหา
**1. ดูรหัสที่ host ใช้** — เปิด `_token_check.php?flush=1` ดู `host_token` (`starts` / `ends`)
   - `?flush=1` สั่งล้างแคช (OPcache) ของ config.php ให้ PHP อ่านไฟล์ใหม่
   - `received_x_header` = 0 / `match: false` เป็นปกติเมื่อเปิดจากเบราว์เซอร์ (เบราว์เซอร์ไม่ได้ส่งรหัส) — ไม่ต้องสนใจ
   - `starts`/`ends` ไม่ใช่รหัสใหม่ → config.php บน host ยังไม่ใช่รหัสใหม่:
     - ตรวจว่าอัปโหลด config.php ขึ้น `app-salesproject/config/` จริง (`config_file_time` = เวลาอัปโหลดล่าสุด)
     - ในไฟล์บน host บรรทัด `define('QUOTE_API_TOKEN', …)` ที่ไม่มี `//` ต้องมีบรรทัดเดียว (ชุด localhost ต้องมี `//`)
     - ถ้าไฟล์ถูกแล้วแต่ค่ายังเก่า: Plesk → sales.thaitaiyo.co.th → **PHP Settings** → กด **OK** (ไม่ต้องแก้) เพื่อรีสตาร์ท PHP

**2. ดูรหัสที่ระบบใบเสนอราคาใช้** — เปิด `_token_check.aspx` เทียบ 2 ส่วน
   - **runtime** = รหัสที่เว็บใช้อยู่จริงในหน่วยความจำ
   - **ไฟล์ App_Data** = รหัสที่เขียนในไฟล์ตอนนี้ + ที่อยู่ไฟล์ + เวลาแก้ไขล่าสุด

   | ผล | สาเหตุ | แก้ |
   |---|---|---|
   | ไฟล์ = รหัสใหม่ แต่ **runtime = รหัสเดิม** | **เว็บยังไม่ได้อ่านไฟล์ใหม่** (สาเหตุที่เจอจริง) — IIS ไม่เฝ้าดูไฟล์ App_Data | เปิด `Web.config` ในโฟลเดอร์เดียวกับ App_Data → Space แล้ว Backspace → **Save** (หรือ Recycle Application Pool) → รีเฟรชหน้าเช็ค runtime ต้องเปลี่ยน |
   | ไฟล์ ≠ รหัสใหม่ | แก้ผิดไฟล์ / ผิดเครื่อง / ยังไม่ได้ Save | แก้ไฟล์ตาม "ที่อยู่ไฟล์" ที่หน้าเช็คบอก (เครื่องจริง = `D:\project\web_quotation\App_Data\…`) |
   | ไม่มีบรรทัด `<add>` ที่เปิดอยู่ / เปิดอยู่หลายบรรทัด | comment ครอบผิด | เปิดเฉพาะชุด Host — ถ้าเปิดหลายบรรทัด ระบบใช้บรรทัดหลังสุด |
   | "อ่านไฟล์ไม่ได้ (XML ผิดรูปแบบ?)" | มี `--` ใน comment / แท็กไม่ปิด | แก้ไฟล์ให้ถูกรูปแบบตาม `appsettings.local.config.example` |
   | `SalesProjectApiUrl` เป็น `localhost` | เปิดชุด localhost ค้างบนเครื่องจริง | ปิดชุด localhost ให้เหลือแค่ชุด Host |

**3. เมื่อ host = runtime ของระบบใบเสนอราคา (4 ตัวแรก/ท้ายตรงกัน)** → หน้าใบเสนอราคา Ctrl+F5 → แท็บ "รอเปิดใบเสนอราคา งาน Project" ต้องไม่มีแถบแดง

**4. ลบไฟล์เช็คออกจากเครื่องจริงทั้ง 2 ไฟล์** (`api/_token_check.php` บน host, `_token_check.aspx` บน 200.200.200.4) — เก็บไว้เฉพาะในโปรเจกต์

### ⚠️ อย่าทดสอบด้วยการ "ใส่รหัสเดิมกลับแล้วเชื่อมได้"
ระบบใบเสนอราคายังใช้รหัสเดิมในหน่วยความจำอยู่แล้ว (ถ้ายังไม่ได้ Save Web.config) — ใส่รหัสเดิมกลับในไฟล์แล้ว "เชื่อมได้"
ไม่ได้แปลว่าไฟล์ถูกอ่าน ทำให้สรุปผิดว่า host จำค่าเดิม (เจอจริง 2026-10-15)

### ⚠️ เครื่อง dev อย่าเปิดชุด Host ค้างไว้
ถ้า `App_Data\appsettings.local.config` บนเครื่อง dev เปิดชุด Host ระบบใบเสนอราคาบน dev (ฐานข้อมูล **TEST**) จะต่อไประบบงานขาย**จริง**
— ออกใบ/ยืนยันใบบน dev แล้วผลจะไปเปลี่ยนดีลจริงบน host — สลับกลับเป็นชุด localhost + Save `Web.config` ของเครื่อง dev ทุกครั้งหลังใช้

## หมายเหตุทางเทคนิค
- ระบบใบเสนอราคาส่งรหัส 2 ทาง: header `Authorization: Bearer …` และ `X-Quote-Api-Token: …`
  เพราะ host (Plesk Apache + PHP-FPM) ตัด `Authorization` ทิ้งก่อนถึง PHP (พบตอนขึ้นระบบ 2026-10-15) — ระบบงานขายอ่านได้ทั้ง 2 ทาง
  (`App_Code/clsSalesProjectApi.cs` / `api/quote_requests_ext.php` ฟังก์ชัน `requireQuoteApiToken()`)
- Windows Server ของ 200.200.200.4 ต้องบังคับ TLS 1.2 ถึงจะต่อ host ได้ — โค้ดตั้งไว้แล้ว (ใช้ตอนทดสอบด้วย PowerShell ด้วย)
- เป็นการเรียกแบบ server ต่อ server ไม่เกี่ยวกับ CORS ไม่ต้องตั้งค่า CORS เพิ่ม
- ระบบงานขาย `QUOTE_API_TOKEN` ว่าง = ปิด API นี้ (ตอบ 503) / ไม่มีบรรทัดนี้เลย = error 500
- เครื่อง dev: token อยู่ใน env ของ dev server `ebidding-qt` (`.claude/launch.json` ไม่ขึ้น git) + `App_Data\appsettings.local.config` ชุด localhost — คนละค่ากับเครื่องจริง
- ไฟล์ระบบใบเสนอราคาที่**ห้ามอัปโหลดจากเครื่อง dev ตรงๆ** (ชี้เครื่อง dev): `App_Code/clsmaincontrol.cs` (ฐานข้อมูล TEST), `js/apiserver.js` (localhost), `Web.config` (แก้บนเครื่องจริงเอง) — ส่วน `App_Data/appsettings.local.config` อัปโหลดได้**หลังสลับเป็นชุด Host แล้วเท่านั้น**
